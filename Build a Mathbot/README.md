# JavaScript  
## Build a Mathbot  
This is a project from freeCodeCamp  
What I learn:  
- `Math.random()`: generates a random number between 0 and 1.
- `Math.min()`: finds the smallest number.
- `Math.max()`: finds the largest number.
- `Math.floor()`: rounds a number down.
- `Math.ceil()`: rounds a number up.
- `Math.round()`: rounds a number to the nearest integer.
- `Math.trunc()`: removes the decimal part of a number.
- `Math.sqrt()`: calculates the square root.
- `Math.cbrt()`: calculates the cube root.
- `Math.abs()`: returns the absolute value.
- `Math.pow()`: calculates a number raised to a power.
