# JavaScript  
## Build a String Formatter  
This project is from freeCodeCamp  
What I learn:  
- Variable  
  Used to store data value
  
- console.log()  
  Used to display output in the console
  
- trim()  
  Used to remove the whitespace to the beggining and the end of the string

- trimStart()  
  Used to removed whitespace from the beggining of the string

- trimEnd()  
  Used to removed whitespace from the end of the string

- toUpperCase()
  Used to convert all characters in a string to uppercase

- toLowerCase()  
  Used to convert all characters in a string to lowercase

- slice()  
  Used to extract a portion of a string
